
# Setu — E-Commerce Marketplace Backend

Setu is a marketplace backend built with Python and FastAPI, designed to support product discovery, customer accounts, shopping carts, secure checkout, and order management.

## Project Goals

- Build a modular, maintainable REST API.
- Implement authentication and role-based authorization.
- Manage products, inventory, carts, and orders.
- Integrate payment processing and email notifications.
- Apply database migrations, automated testing, and secure configuration.

## Technology Stack

- **Language:** Python
- **API Framework:** FastAPI
- **Database:** PostgreSQL
- **ORM:** SQLAlchemy
- **Database Migrations:** Alembic
- **Testing:** pytest
- **Version Control:** Git and GitHub
